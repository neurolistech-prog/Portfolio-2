05 //

Optimisation de Requêtes SQL

Une bonne application repose avant tout sur une base de données relationnelle saine. Je conçois des schémas relationnels normalisés sous PostgreSQL et MySQL.


Je maîtrise l'écriture de requêtes complexes incluant des jointures multiples (JOIN), des agrégations avancées et des sous-requêtes imbriquées, tout en veillant à la mise en place d'index stratégiques pour optimiser les temps d'exécution sur les gros volumes de données.

SELECT p.id, p.title, COUNT(t.id) AS total_tasks
FROM projects p
LEFT JOIN tasks t ON p.id = t.project_id
WHERE p.status = 'active'
GROUP BY p.id
ORDER BY total_tasks DESC;
