Sécurité Offensive & Éthique

Mon rôle en tant que chercheur indépendant ("Google Hunter") m'impose une discipline rigoureuse : auditer l'exposition des systèmes informatiques pour colmater les failles logiques. Je développe mes logiciels avec la philosophie Security by Design, éliminant les risques en amont.

Cette expertise garantit que les applications SaaS et architectures cloud que je déploie résistent aux vecteurs d'attaque répertoriés dans l'OWASP Top 10.

→
Analyse Avancée des Inputs — Validation stricte par schémas typés (Zod/Pydantic) pour contrer toutes les injections de scripts.
→
Durcissement des Endpoints — Mise en place de passerelles d'authentification par clés cryptographiques et contrôle du Rate Limiting strict.
→
Gestion des Privilèges — Segmentation hermétique des connexions de bases de données (Principle of Least Privilege).

Laboratoire Matériel & Systèmes Embarqués

L'abstraction logicielle prend tout son sens lorsqu'elle s'interface avec le monde physique. Mon travail englobe la programmation de microcontrôleurs et la conception d'outils matériels sur-mesure.

Câble OTG Intelligent avec Écran Intégré : Conception d'un prototype matériel basé sur l'architecture du microcontrôleur Raspberry Pi RP2040-Zero. Écrit en C++, le micrologiciel intercepte et analyse le flux de paquets de données transitant dans le câble pour l'afficher en temps réel sur un mini-écran OLED de contrôle.

Prototypes IoT & Robotique : Développement sur cartes Arduino de pointe (MKR IoT Carrier) et cartes micro:bit pour programmer la cinématique et l'évitement d'obstacles autonomes de plateformes robotisées terrestres.

[ FIRMWARE ARCHITECTURE - RASPBERRY PI RP2040-ZERO ]
--------------------------------------------------
#include <hardware/usb.h>
#include <pico/stdlib.h>
#include <OLED_Driver.h>

int main() {
    stdio_init_all();
    oled_initialize_spi();
    usb_sniffer_init();

    while(true) {
        uint8_t packet_buffer[64];
        if (usb_sniff_packet(packet_buffer)) {
            oled_render_hex_stream(packet_buffer);
        }
        tight_loop_contents();
    }
    return 0;
}
